# LifeOS

A personal life operating system built with React JSX.

## Files

- `index.html` — entry point (loads JSX files via CDN)
- `LifeOS_app.html` — self-contained bundled version (no dependencies)
- `lifeos/` — React JSX source components:
  - `app.jsx` — root app component
  - `nav.jsx` — navigation
  - `state.jsx` — global state management
  - `theme.jsx` — theming
  - `primitives.jsx` — base UI primitives
  - `flows.jsx` — user flows
  - `design-canvas.jsx` — design canvas
  - `browser-window.jsx` — browser window component
  - `ios-frame.jsx` — iOS frame component
  - `tweaks-panel.jsx` — tweaks panel
  - `screen-character.jsx` — character screen
  - `screen-directive.jsx` — directive screen
  - `screen-ledger.jsx` — ledger screen
  - `screen-onboarding.jsx` — onboarding screen
  - `screen-quests.jsx` — quests screen

## Usage

Open `index.html` in a browser, or open `LifeOS_app.html` for the fully self-contained version.
